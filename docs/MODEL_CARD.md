# 模型卡

## 模型组成

### explicit-mf + explicit-knn

显式评分经全局偏差、用户偏差和作品偏差校准，再按用户评分标准差归一化。正式排序使用 48 维残差 MF；浏览器根据用户本地评分生成用户向量。UserKNN 继续负责相似用户支持证据和 affinity 校准。索引保留 IUF 与评分事件稀有度数组，用于可复现实验，当前正式计算不启用它们。

2026-07-31 构建结果：

- 1,516,490 条清洗后评分
- 24,276 名有效用户
- 17,936 部有协同证据的作品
- 浏览器二进制索引 24,791,440 bytes
- MF 物品因子 1,004,440 bytes

2,000 名用户的最新高分作品时间留出评估中，Bayesian Popularity、mean-centered UserKNN、surprise-weighted UserKNN 和残差 MF 的 NDCG@10 分别为 0.0470、0.0721、0.0675 和 0.0830。残差 MF 相对 UserKNN 的提升为 0.0109，1,000 次 bootstrap 的 95% 区间为 [0.0004, 0.0225]。正式排序选择残差 MF；surprise 版本不启用。

### implicit-recall

公开收藏状态生成候选召回向量。当前构建使用 48 维稀疏 SVD，后续需要用时间留出结果与 implicit ALS、BPR 比较后才能确定正式算法。

- 9,349,534 条带有效状态的交互
- 8,048,725 条正向训练交互
- 1,124,116 条负向训练交互
- 108,156 名用户
- 45,008 部作品

### content-graph

标签、开发者、平台和作品关系通过确定性特征映射生成 64 维向量。该向量只用于候选扩展，不修改 affinity。

- 65,116 部作品
- 205,048 个有效标签关联
- 32,202 条作品关系

## 输出规则

- affinity 只在至少 5 名相似用户支持时显示。
- 评分证据不足的作品进入“探索”，不显示 affinity。
- 已看、游玩中、搁置、计划游玩和不感兴趣作品不进入推荐。
- 成人作品保留，未确认年龄时遮罩封面。

## 当前限制

- 中文官方标题只有 4,356 部，其他作品显示日文或英文标题。
- 跨来源关联来自社区数据，可能存在遗漏或错误。
- 当前 SVD 收藏状态模型尚未完成 ALS/BPR 对照，因此是可运行候选模型，不是最终选定模型。
- 残差 MF 的 NDCG@20 为 0.0943，LowPop NDCG@10 为 0.0359；对应 UserKNN 为 0.0884 和 0.0307。
- 残差 MF 的 long-tail coverage 不高，因此每次 Top 40 固定保留最多 8 个由状态与内容图产生的“探索”位置；探索作品不显示 affinity。
- Demo 模型只有 20 部作品和 20 个合成用户，只用于验证浏览器安装与交互。
